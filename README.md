# Consensus Agent

Consensus Agent is an intelligent application that compares live prediction market probabilities (from Polymarket or Kalshi) against a consensus probability generated by three state-of-the-art LLMs (GPT-4o, Claude 3.5, Gemini 1.5 Pro).

It scrapes recent news regarding the event, passes the context to the LLMs, and calculates a weighted consensus. If the discrepancy between the market probability and the consensus probability exceeds 10%, it generates a detailed trade thesis.

## Features
- **Market Integration**: Supports URLs from [Polymarket](https://polymarket.com) and [Kalshi](https://kalshi.com).
- **News Scraping**: Automatically fetches the 5 most recent and credible news articles using DuckDuckGo.
- **Multi-LLM Consensus**: Calculates a weighted average probability based on historical accuracy.
- **Trade Thesis**: Generates a detailed buy/sell thesis when an edge is detected.
- **Beautiful UI**: Interactive and clean web interface powered by Streamlit.

## Installation on macOS

Follow these steps to set up the project on macOS:

### 1. Prerequisites
Ensure you have Homebrew and Python 3 installed. If not, open your Terminal and run:
```bash
# Install Homebrew
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

# Install Python 3
brew install python
```

### 2. Clone the Repository
Clone this repository to your local machine:
```bash
git clone <your-repo-url>
cd <your-repo-folder>
```

### 3. Set Up a Virtual Environment (Recommended)
It's best practice to use a virtual environment to manage dependencies:
```bash
python3 -m venv venv
source venv/bin/activate
```

### 4. Install Dependencies
Install the required Python packages using `pip`:
```bash
pip install -r requirements.txt
```

### 5. Configure API Keys
The agent requires API keys for the LLMs to function properly. Export them in your terminal:
```bash
export OPENAI_API_KEY="your-openai-api-key"
export ANTHROPIC_API_KEY="your-anthropic-api-key"
export GEMINI_API_KEY="your-gemini-api-key"
```
*(Note: If you don't provide these keys, the app will fall back to simulated probabilities for demonstration purposes).*

## Usage

Start the Streamlit web application:

```bash
streamlit run app.py
```

This will automatically open a new tab in your default web browser (usually at `http://localhost:8501`).

1. Paste a Polymarket or Kalshi URL into the input field.
2. Click **Run Analysis**.
3. View the fetched data, news articles, LLM breakdown, and the final trade thesis.
